# Буфер обмена: просмотр и очистка (Windows)

Маленькая программа на Python, которая показывает, что лежит в буфере обмена
и в журнале буфера Windows (Win+V), и позволяет всё это стереть.
Сделана для тех, кто копирует пароли из текстового файла.

## Запуск

Нужны Windows 10/11 и Python 3. Ничего устанавливать через pip не надо.

```
python clipboard_manager.py
```

Если запускать двойным кликом и не хочется видеть чёрное окно консоли,
переименуйте файл в `clipboard_manager.pyw`.

## Что есть в окне

**Сейчас в буфере обмена**: текст, файлы или картинка, которые вставятся по Ctrl+V.
Текст по умолчанию скрыт точками, показать его можно галочкой «Показывать содержимое».
Кнопка «Очистить буфер» стирает его.

**Автоочистка**: если включить, программа сама сотрёт скопированное через
заданное число секунд (как в менеджерах паролей). Галочка «…и удалять этот текст
из журнала Win+V» дополнительно убирает этот же текст из журнала.

**Журнал буфера обмена (Win+V)**: Windows хранит там всё, что вы копировали.
Очистка самого буфера журнал НЕ трогает, поэтому старые пароли остаются там.
Можно удалить выбранные записи (или нажать Delete) либо весь журнал сразу.
Закреплённые записи Windows при полной очистке журнала оставляет.

**Очистить всё**: буфер и журнал одной кнопкой.

Если в Windows включена синхронизация буфера между устройствами, программа
покажет красное предупреждение: скопированное может уходить в облако Microsoft.

## Как это устроено

* Текущий буфер читается и очищается через Win32 API (`ctypes`).
* У журнала Win+V есть только WinRT API, поэтому программа на секунду
  запускает встроенный в Windows PowerShell 5.1 в скрытом окне.
  Текст для удаления передаётся ему через переменную окружения, а не через
  командную строку.
* Программа ничего не сохраняет на диск и никуда не отправляет.

Если журнал выключен (Параметры → Система → Буфер обмена → Журнал буфера обмена),
программа так и напишет, а всё остальное будет работать.

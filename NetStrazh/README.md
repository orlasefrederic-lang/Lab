# Сетевой страж

Android-приложение без root: показывает, какие программы выходят в интернет, куда и сколько
передают, и работает как файрвол. Любому приложению можно запретить интернет полностью,
только по Wi-Fi или только по мобильной сети.

Минимальная версия Android 10, проверялось под Android 14/15 (Xiaomi / HyperOS).

## Что умеет

| Вкладка | Что показывает |
|---|---|
| **Сейчас** | Приложения, которые прямо сейчас в сети: число соединений, скорость ↓/↑, адреса, объём с момента включения |
| **Журнал** | Каждое соединение, DNS-запрос и заблокированная попытка: время, приложение, сайт/IP, порт, протокол, байты. Фильтры и поиск |
| **Трафик** | Сколько трафика потратило каждое приложение за сегодня / 7 / 30 дней (Wi-Fi и мобильный отдельно), запущено ли оно сейчас и когда запускалось. Данные берутся у самого Android, поэтому эта вкладка работает даже при выключенной защите |
| **Файрвол** | Блок-лист: добавить приложение, убрать, отдельно запретить Wi-Fi или мобильный интернет |

Нажатие на приложение в любом списке открывает его карточку: переключатели файрвола, трафик,
куда оно подключалось, какие домены запрашивало, последние соединения. Там же есть режим
«Пускать мимо Стража» для приложений, которые не работают через VPN (например, некоторые банки).

## Установка

1. Скачайте `NetStrazh-*.apk` на телефон (со страницы **Releases** или из артефактов GitHub Actions).
2. Откройте файл и разрешите установку из этого источника.
3. Запустите «Сетевой страж» и включите переключатель вверху:
   - Android спросит разрешение на VPN. Это нужно: так приложение видит и фильтрует трафик. Всё
     происходит на самом телефоне, никакие данные никуда не отправляются;
   - на вкладке «Трафик» нажмите «Открыть настройки» и дайте доступ к истории использования.

**Xiaomi / HyperOS.** Чтобы система не выключала защиту в фоне: в настройках приложения
включите «Автозапуск», в «Контроле активности» выберите «Нет ограничений», а в списке
недавних приложений закрепите карточку. Можно включить «Постоянную VPN»: Настройки →
Подключения → VPN → «Сетевой страж». Эти же подсказки есть в приложении (вкладка «Файрвол»).

## Как это работает

Приложение поднимает локальный VPN (`VpnService`): весь трафик телефона идёт в виртуальный
интерфейс внутри приложения, а не на чужой сервер.

* **TCP.** Пакеты приложения подменяются (NAT) так, что соединение принимает TCP-стек ядра
  Android на локальном сокете «Стража». Дальше «Страж» сам открывает соединение к настоящему
  адресу и пересылает данные в обе стороны, считая байты. Собственную реализацию TCP писать не
  нужно, поэтому скорость и надёжность как у обычного соединения.
* **UDP** (включая QUIC/HTTP3) пересылается через отдельные сокеты по потокам.
* **DNS.** Приложениям выдаётся DNS-сервер `10.111.0.53`; запросы передаются настоящему DNS
  сети и записываются, поэтому в журнале видны имена сайтов, а не только IP.
* **Имя сайта** берётся также из TLS SNI (HTTPS) и заголовка `Host` (HTTP), так что домены видны,
  даже если включён «Частный DNS».
* **Владелец соединения** определяется через `ConnectivityManager.getConnectionOwnerUid`.
* **Блокировка.** TCP-соединения заблокированного приложения сбрасываются сразу (RST), его UDP
  отбрасывается. При добавлении приложения в блок-лист его открытые соединения рвутся.

## Ограничения

* Одновременно на Android может работать только один VPN: вместе с другим VPN «Страж» не работает.
* `ping` (ICMP) через VPN не проходит; обычные приложения от этого не страдают.
* DNS-запросы заблокированных приложений не блокируются (кэш DNS в Android общий для всех
  приложений), но соединения после них блокируются.
* По умолчанию VPN работает только с IPv4, и Android переводит приложения на IPv4. Пропуск IPv6
  можно включить галочкой на вкладке «Файрвол» (экспериментально).
* Журнал хранится 7 дней, только на телефоне.

## Сборка

```bash
cd NetStrazh
./gradlew testDebugUnitTest assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

GitHub Actions (`.github/workflows/android.yml` в корне репозитория) собирает APK на каждый push. При push в `main`,
на тег `v*` или при ручном запуске (Actions → Android APK → Run workflow) APK публикуется в Releases.

APK подписывается ключом `NetStrazh/app/signing/netstrazh.jks` (пароль `netstrazh`). Ключ лежит в
репозитории намеренно, чтобы сборки с любой машины и из CI ставились поверх друг друга без
удаления приложения. Репозиторий публичный, поэтому подписать APK этим ключом может кто угодно:
ставьте «Стража» только из этого репозитория.

## Структура

```
app/src/main/java/lab/netstrazh/
  net/    разбор IP/TCP/UDP-пакетов, контрольные суммы, DNS, SNI (чистый Kotlin, покрыт тестами)
  vpn/    VpnService, движок: TCP NAT, UDP-ретранслятор, учёт соединений, отслеживание сети
  data/   правила файрвола, журнал (SQLite), имена приложений, системная статистика трафика
  ui/     экраны (обычные Android View, без сторонних библиотек)
```

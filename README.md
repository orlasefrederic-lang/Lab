## hardware_info.py — сведения об оборудовании компьютера (Windows и Linux)

Программа на Python собирает подробную информацию обо всём железе компьютера и
сохраняет отчёт в трёх форматах: **TXT** (то же, что в консоли), **HTML**
(удобно читать в браузере) и **JSON** (для обработки другими программами).

Сторонние библиотеки не нужны, программа только читает сведения и ничего не
меняет в системе.

* **В Windows** данные берутся из WMI/CIM через встроенный PowerShell, из реестра
  и напрямую у драйверов (батарея, журнал SMART NVMe-дисков).
* **В Linux** — напрямую из ядра (`/sys`, `/proc`), таблиц прошивки SMBIOS
  (модули памяти, серийные номера) и у NVMe-контроллера (журнал SMART).
  Если в системе есть `smartctl` или `nvidia-smi`, программа возьмёт у них
  дополнительные данные, но и без них обходится.

### Проверка при покупке: не б/у ли железо

Сразу после сводки идёт раздел **«Проверка состояния»** с понятным итогом
(✔ — в порядке, ⚠ — обратите внимание, ✖ — неисправность):

| Что проверяется | Чего ждать от нового компьютера |
|---|---|
| Батарея | износ 0–5 %, почти нет циклов заряда |
| Накопители | наработка — единицы или десятки часов, записано немного, никаких ошибок SMART, переназначенных и нестабильных секторов |
| Оперативная память | модули работают на паспортной частоте; один модуль при свободном слоте — медленный одноканальный режим |
| Устройства | нет неисправных устройств |

Если ноутбук продают **без Windows** (с FreeDOS, с Linux или вообще без системы)
или не хочется трогать установленную систему, загрузитесь с флешки с Ubuntu —
см. «Запуск с загрузочной флешки» ниже.

### Что попадает в отчёт

| Раздел | Что показывается |
|---|---|
| Сводка | Главное о компьютере на одном экране |
| Проверка состояния | Итог: износ батареи, наработка и ошибки дисков, память, устройства |
| Компьютер | Производитель, модель, тип корпуса, серийный номер, UUID, признаки виртуальной машины |
| Операционная система | Версия и выпуск Windows (например, 23H2) или дистрибутив и ядро Linux, время работы |
| BIOS / UEFI | Производитель, версия, дата, режим загрузки (UEFI/Legacy), Secure Boot, версия SMBIOS |
| Материнская плата | Производитель, модель, ревизия, серийный номер |
| Процессор | Модель, ядра/потоки, базовая и турбо-частота, кэш L2/L3, сокет, виртуализация |
| Оперативная память | Общий объём, тип (DDR4/DDR5…), скорость, слоты; каждый модуль: объём, частота, напряжение, производитель, партномер |
| Видеокарты | Модель, **точный объём видеопамяти**, драйвер, текущий режим, VEN:DEV |
| Мониторы | Модель (у ноутбука — модель матрицы встроенного экрана), производитель, диагональ, родное разрешение и частота, тип подключения (HDMI/DP…), дата выпуска |
| Накопители | Модель, SSD/HDD, NVMe/SATA/USB, объём, прошивка, состояние, температура, износ, **наработка, объём записанного**, ошибки SMART; разделы и тома |
| Сетевые адаптеры | Ethernet/Wi-Fi, MAC, скорость, IP-адреса, шлюз, DNS, драйвер |
| Звук, устройства ввода, камеры, Bluetooth, USB | Устройства, производители, VID:PID, драйверы, аудиокодеки (Linux) |
| Батарея | Заряд, паспортная и текущая ёмкость, **износ**, число циклов |
| Принтеры, оптические приводы, TPM | Основные сведения |
| Устройства с неполадками | Всё, что в Диспетчере устройств с ошибкой или без драйвера, с подсказкой, **что это за устройство** и нужен ли ему драйвер (например, служебные Bluetooth-каналы наушников вроде Airoha_APP, OTA1, xiaoai) |
| Все устройства | Полный список устройств по классам с драйверами |

### Требования

* Windows 10 или 11, либо любой современный Linux (Ubuntu, Mint, Fedora, Debian…);
* Python 3.8 или новее. В Linux он почти всегда уже установлен, для Windows —
  <https://www.python.org/downloads/> (при установке отметьте «Add python.exe to PATH»).

### Запуск в Windows

**Проще всего:** дважды щёлкните `hardware_info.bat`. Отчёт появится в окне,
файлы сохранятся рядом с программой, а HTML-версия откроется в браузере.

Из командной строки:

```bat
python hardware_info.py
python hardware_info.py --elevate
```

Для **полного** отчёта (TPM, наработка и износ дисков, подробности батареи)
нужны права администратора — параметр `--elevate` попросит их сам.

### Запуск в Linux

```sh
sh hardware_info.sh
```

или то же самое вручную:

```sh
python3 hardware_info.py --elevate --open
```

Для полного отчёта (модули памяти, серийные номера, SMART дисков) нужны права
root: с параметром `--elevate` программа спросит пароль через `sudo`, а отчёт
сохранит и откроет от имени обычного пользователя. Можно запускать и просто
`sudo python3 hardware_info.py`.

SMART NVMe-дисков программа читает сама. Для SATA- и USB-дисков установите
smartmontools: `sudo apt install smartmontools`.

### Запуск с загрузочной флешки

Так можно проверить любой компьютер — с FreeDOS, без системы или с Windows,
которую не хочется трогать. Ничего на компьютер не устанавливается.

1. Скачайте Ubuntu (<https://ubuntu.com/download/desktop>) и запишите на флешку,
   например программой Ventoy (<https://www.ventoy.net>) — тогда на флешку
   можно просто скопировать ISO-файл, а рядом положить `hardware_info.py`
   и `hardware_info.sh`.
2. Загрузите компьютер с флешки (меню загрузки обычно открывается клавишей
   F12, F11, F8 или Esc при включении) и выберите «Попробовать Ubuntu».
3. Откройте файловый менеджер, зайдите на флешку, щёлкните правой кнопкой
   по пустому месту → «Открыть в терминале» и выполните:

   ```sh
   sh hardware_info.sh
   ```

Отчёт сохранится прямо на флешку и откроется в браузере. В Live-режиме
пароль для `sudo` не нужен.

### Параметры

| Параметр | Назначение |
|---|---|
| `-o ПАПКА`, `--output ПАПКА` | Куда сохранять отчёты (по умолчанию — текущая папка) |
| `-f txt html json` | Какие форматы сохранять (по умолчанию все три) |
| `--open` | Открыть HTML-отчёт после создания |
| `--elevate` | Получить права администратора (в Linux — root через sudo) |
| `--anon` | Скрыть серийные номера, UUID, MAC и IP-адреса (в том числе MAC Bluetooth-устройств внутри ИД оборудования), имена компьютера и пользователя — удобно, чтобы выложить отчёт на форум |
| `--no-devices` | Не включать полный список устройств |
| `--no-save` | Только вывести отчёт в консоль, без файлов |
| `-q`, `--quiet` | Не выводить отчёт в консоль, только сохранить файлы |
| `--pause` | Ждать нажатия Enter перед закрытием окна |
| `--dump-raw` | Дополнительно сохранить «сырые» данные (для отладки) |
| `--load-raw ФАЙЛ` | Построить отчёт из ранее сохранённых сырых данных (на любой системе) |

### Как собрать в один .exe (по желанию)

```bat
pip install pyinstaller
pyinstaller --onefile --name hardware_info hardware_info.py
```

Готовый `dist\hardware_info.exe` запускается на любом компьютере с Windows,
даже без установленного Python.
